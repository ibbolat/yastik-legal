# Yastık — Yasal Sayfalar

Bu repository, **Yastık – Altın & Döviz Takibi** uygulamasının Google Play ve
kullanıcı erişimi için hazırlanan herkese açık statik yasal sayfalarını içerir.

## İçerik

- `index.html` — yasal sayfalar ana sayfası
- `privacy/index.html` — Gizlilik Politikası
- `delete-account/index.html` — hesap ve veri silme talebi
- `privacy.html` — Gizlilik Politikası için geriye uyumlu yönlendirme
- `account-deletion.html` — hesap silme sayfası için geriye uyumlu yönlendirme
- `terms.html` — Kullanım Koşulları

Sayfalar JavaScript, çerez, analytics, harici font veya CDN kullanmaz.
